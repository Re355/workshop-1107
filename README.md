# NVDAナビゲーター

Webページ上にNVDAのショートカット一覧を固定表示するChrome拡張機能です。パネルの位置や文字色、背景色を変更できます。

## 機能

- NVDAの基本ショートカットをカテゴリ別に表示
- パネルを画面の四隅または中央に固定表示
- 文字色と背景色を設定画面から変更。設定は表示中のパネルにも反映
- ページの要素検知や入力内容の取得は行わない

## Chromeへの読み込み

1. Chromeで `chrome://extensions` を開きます。
2. 右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を選びます。
4. このリポジトリのルート（`manifest.json` があるフォルダー）を選びます。
5. Webページで拡張機能のアイコンをクリックし、「パネルを表示／閉じる」を選びます。

位置や色を変えるにはポップアップの「表示設定を開く」を選びます。パネルは閉じるボタンからも閉じられます。Chromeの設定ページなど、パネルを重ねられないページでは、代わりにポップアップ内にショートカット一覧を表示します。表示に失敗した場合は、ページ制限や通信エラーなど原因に応じた案内を確認してください。コードを更新した直後は、拡張機能と対象ページの両方を再読み込みしてください。

コードを変更した後は、拡張機能の再読み込みを行ってください。必要に応じて対象のWebページも再読み込みします。

## 権限について

`activeTab` と `scripting` を使い、ユーザーが表示操作を行ったタブにだけパネルを追加します。設定を保存するため `storage` を使用します。すべてのサイトへの常時アクセス権限は要求しません。Chromeの設定ページなど、拡張機能からスクリプトを実行できないページではパネルを表示できず、その旨を案内します。

NVDAキーは通常 Insert または Caps Lock です。記載したコマンドは主にブラウズモードで使用し、NVDAの設定やページの状態によって動作が異なる場合があります。

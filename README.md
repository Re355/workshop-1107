# NVDAナビゲーター

Webページでフォーカス中、またはクリックした要素の種類に合わせて、NVDAのショートカットを案内するChrome拡張機能です。

## 機能

- NVDAの基本ショートカットをカテゴリ別に表示
- リンク、見出し、フォーム入力欄、ボタンなどを検知し、おすすめのコマンドを強調表示
- ページの要素名は拡張機能のポップアップ内だけで表示し、外部へ送信しない

## Chromeへの読み込み

1. Chromeで `chrome://extensions` を開きます。
2. 右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を選びます。
4. このリポジトリのルート（`manifest.json` があるフォルダー）を選びます。
5. Webページを開き、拡張機能のアイコンをクリックします。

コードを変更した後は、拡張機能の再読み込みを行ってください。必要に応じて対象のWebページも再読み込みします。

## 権限について

`activeTab` と `scripting` を使い、ユーザーが拡張機能を開いたタブでだけ要素検知用スクリプトを実行します。すべてのサイトへの常時アクセス権限は要求しません。Chromeの設定ページなど、拡張機能からスクリプトを実行できないページでは要素を表示できません。

NVDAキーは通常 Insert または Caps Lock です。記載したコマンドは主にブラウズモードで使用し、NVDAの設定やページの状態によって動作が異なる場合があります。
